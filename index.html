Возможности

Всё что нужно для модификации IPA

Полный цикл работы с iOS-приложениями — от распаковки до установки через SideStore, AltStore или TrollStore.

📦

IPA и TIPA

Распаковка и упаковка с сохранением Unix-прав. Автоопределение формата, ZIP_STORED для TrollStore.

🏪

TrollStore

Автоподготовка entitlements, настройка Info.plist и упаковка без сжатия для быстрой установки.

✏️

Info.plist

Имя, версия, номер сборки, Bundle ID. Каскадное обновление во всех PlugIns, Watch и appex.

🖼️

Замена иконки

5 методов: гибридный (маскировка Assets.car), только BOM, только loose, стандарт, удаление.

💉

Инъекция твиков

.dylib, .deb, .zip, .tar.* — фреймворки и бандлы автоматически копируются в Frameworks/.

🔧

Hex патчер

Встроенный интерактивный Hex-редактор. Поиск, замена, работа по смещению, undo и бэкапы.

🛠️

Расширенные патчи

Понижение iOS, удаление плагинов, Watch, URL-схем, ограничений по устройствам.

🛡️

Безопасность

Zip Slip защита, сканирование dylib на опасные вызовы, строгий парсинг Mach-O.

🌐

Web Transfer

Локальный HTTP-сервер с ПИН-кодом и авто-баном для передачи файлов по Wi-Fi.

FAQ

Частые вопросы

Нужен ли джейлбрейк?

Нет. Установка через AltStore, SideStore или TrollStore работает на стоковой iOS.

Какие платформы поддерживаются?

Pythonista 3 и a-Shell mini на iOS/iPadOS, а также нативный Python на macOS, Linux и Windows.

Можно ли откатить изменения?

Скрипт никогда не изменяет исходный файл — результат всегда сохраняется в новый с суффиксами (_tweaked, _icon, _patched). Точечные правки через Hex-патчер откатываются через менеджер бэкапов.

Почему инъекция твика не удалась?

Нехватка места в заголовке Mach-O, неподдерживаемая архитектура (32-бит) или исходный файл зашифрован (App Store бинарник без расшифровки).

Какой метод замены иконки выбрать?

Гибридный (пункт 1) — безопасный и эффективный; не трогает Assets.car целиком и не вызывает крашей на iOS 15+.

Обязателен ли Pillow?

Нет. Без Pillow иконки копируются без ресайза, но функционально работают.

Чем отличается .tipa от .ipa?

.tipa — формат для TrollStore, упаковывается без сжатия (ZIP_STORED), содержит специальные entitlements-флаги. Скрипт автоматически определяет формат.
